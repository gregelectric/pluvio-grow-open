# 3D-Printed Parts — Pluvio Grow M5

Eight printed parts for the confirmed M5 build. Print in PETG (or PLA), ~0.2 mm layers, 3–4 walls, ~25 % infill. Most parts are
designed to print **without supports** — the one exception is the **chassis-bottom
pockets**, which need supports. Orient the dome/shroud open-side-down.

> **Tested print.** These parts were printed on a **Bambu P1S / H2S** with a
> **0.6 mm nozzle**, in **PETG**, at ~**25 % infill**. The 0.6 mm nozzle prints
> the whole set comfortably; nothing here needs fine-nozzle detail.
